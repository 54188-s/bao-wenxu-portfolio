# Apple Universe · 苹果设计宇宙

非官方苹果粉丝数字展览馆。唯一 HTML 入口是 `index.html`，样式、产品数据、Hash Router、交互与原创 SVG 结构图全部在该文件中。无需 npm、框架、CDN 或构建步骤。

已按第二轮反馈完成视觉精修：产品馆采用大幅产品展示，统一字体、内容宽度、圆角与留白；减少嵌套边框，规格与说明分层呈现；手机型号选择改为单行横向滚动。改版前后截图保存在 `qa/screenshots/polish-before` 与 `qa/screenshots/polish-final`。

## 运行

若本地网址提示“拒绝连接”，说明预览服务没有运行。可双击 `start-preview.cmd` 启动，然后访问 `http://127.0.0.1:8765/`；使用期间保留启动窗口。也可按下方方式直接打开 HTML。

直接双击 `index.html`。请保留与其同级的 `assets` 文件夹，产品图片均为本地文件。核心页面、搜索、主题、收藏、颜色视角切换、拆解和大图浏览在 `file://` 下可用。

可选 HTTP 预览：

```powershell
& 'D:\767\python3\python.exe' -m http.server 8765 --bind 127.0.0.1 --directory 'D:\767\apple-universe'
```

打开 `http://127.0.0.1:8765/`。收藏和主题保存在当前浏览器、当前来源的 localStorage；不同浏览器和 `file://` / HTTP 来源互不共享数据。限制本地存储的浏览器中，本次交互仍可使用，并显示无法持久保存的提示。

## 真实性与技术边界

- 本站是历代设计展览，**不是实时在售产品目录**。各产品卡片均保留年份，不把后续产品能力套入旧型号。
- 拆解与外观 SVG 是原创**结构／外形概念示意**。独立零件具备真实的交互、几何形状和一一对应的说明，但不表示精确内部位置、零件厚度、电路版图或维修步骤，也不是分件三维扫描模型。
- 主要产品馆明确标注结构解析的具体案例，不把该案例与型号选择器里的其他机型混用。MacBook Air M3 的解析没有添加风扇。
- 角度控件对官方照片施加二维透视，不提供不存在的真实多角度照片。Air / XR 的前后侧面切换使用明确标注的外形示意，大图弹窗保留官方图片。
- 电影感模块采用真实运行的 CSS 动画，标注为无音轨动画演示，不使用无效视频按钮。
- 系统界面是视觉语言示意，明确说明不是可运行的操作系统。
- 产品照片来源、作者、许可和原始图址见 `assets/SOURCES.md` 与 `assets/manifest.json`。Apple 照片版权归 Apple；公开可访问不等于通用再发布许可。历史 CC 照片保留作者与相应许可说明。
- 联系人、地址、邮箱和备案信息按照任务书保留“待填写”，未编造。

## 验证

浏览器验收脚本与结果在 `qa` 中；页面截图位于 `qa/screenshots`，最终汇总见 `TEST-REPORT.md`。

环境没有提供原版 browser-harness 插件，因此 `qa/browser_harness.py` 以 Playwright + 本机 Edge 实现同名截图流程接口，执行真实渲染。工具仅用于验收，网站运行不依赖它。

按 AGENTS.md 调用了 vision 服务：默认／Qwen 返回免费额度耗尽（403），OpenAI 未配置 API key；MiMo 备用视觉服务返回余额不足（402）。这些外部分析没有成功，不能记作已通过的视觉模型检查。已保留实际截图，并使用内置视觉能力复核。完整记录见测试报告。
