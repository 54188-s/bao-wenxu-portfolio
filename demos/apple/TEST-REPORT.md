## 真实截图复核

本轮十五页回归截图位于 `qa/screenshots`，重点精修截图位于 `qa/screenshots/polish-final`。十五个桌面页面均保留全页、顶部、中段、底部截图；十五个手机页面保留顶部截图；另保留八组拆解状态与手机零件说明面板。首次交付的旧截图仍保留在 `qa/screenshots/final` 供对照。

使用截图复核对齐、间距、横向溢出、标题断行、图片比例、正文截断、零件标签与弹窗表现。已修正／验证：

| 问题 | 最终处理 |
|---|---|
| 路由聚焦主内容后产生醒目外框 | 仅去掉主内容容器的外框，保留按钮与链接的键盘焦点样式 |
| 拆解模块滚动入场位移影响鼠标悬停定位 | 拆解入场改为淡入，稳定实际命中区域 |
| 拆解标签过长、密集 | 使用对应说明的两位编号，完整名称放在可选择零件导航与说明中 |
| 标题在部分尺寸出现孤立尾字 | 缩短相关章节标题并复核手机断行 |
| 不同设备的屏幕示意过于一致 | 区分 Mac 屏幕、iPad 前摄、Watch 表盘、XR 刘海等形态 |
| 某些素材与型号年代不一致 | 对照官方素材修正产品年份和版本，并给无法唯一确定的配件批次注明边界 |
| 搜索／菜单与背景焦点可能混用 | 使用 modal 焦点循环、背景 inert 与关闭后焦点恢复 |
| 导航后鼠标已在轮播内的边界情况 | 自动轮播同时检查真实悬停状态；仅在精细鼠标设备上使用该检查，避免触屏悬停残留 |

上述截图复核没有发现阻止浏览或互动的明显重叠、截断和横向溢出。自动检查不代表覆盖全部设备、全部浏览器或精确性能基准。

## 产品事实、素材与技术边界

产品事实以 Apple 官方规格、Newsroom 与支持资料核对，链接在页面对应内容旁。图片原始地址、作者、许可见 `assets/SOURCES.md` 和 `assets/manifest.json`。本站展示历代产品，不是实时在售目录；没有将新款能力套入旧型号。

拆解是具备独立几何、选择与说明的原创 **2.5D 结构概念示意**，不提供准确内部位置、厚度、维修方法或精密三维模型。工程外形与照片透视控件均明确标识其性质。系统界面为视觉语言示意；动态展示为无音轨 CSS 动画。

收藏和主题以当前来源的 localStorage 保存；不同浏览器和 `file://` / HTTP 不共享数据。分享根据浏览器能力采用原生分享或复制链接。联系人、地址、邮箱、备案信息仍为任务书要求的“待填写”。

交付 ZIP 只包含运行文件、文档、素材、验收脚本／记录与几张代表截图；完整截图和本机验收依赖保留在工作目录。无需安装这些依赖即可运行网站。
