# FitFuel Pro 产品案例预览

保留原15个功能页面，新增首次使用引导与中英文营养标签本地 OCR。识别结果是可编辑草稿，核对后才能保存为自定义食物，并按克数加入饮食记录。

在作品集预览根目录双击“启动完整预览.cmd”，进入 FitFuel 案例并点击“体验标签录入”。也可以在本目录运行 `python -m http.server 8000 --bind 127.0.0.1`，打开 `http://127.0.0.1:8000/index.html`。单独双击HTML可以浏览和手动录入，图片识别需HTTP/HTTPS环境。

图片和模型在本地处理，不需要账号或 API 密钥。模型和许可证随目录提供。账户仍是课程演示，不是服务端登录。file与HTTP以及不同端口拥有不同存储来源，记录不会自动复制。

本轮29项功能验收见 `验收结果.json`。测试标签是合成图片；真实包装照片、手机OCR性能和用户试用待验证。按份样例中的g被误识别为9时，脂肪字段保持空白，需人工补录。

维护路径、实现边界和依赖来源见 `本轮功能说明.md`；试用安排见 `用户试用计划.md`。`验收报告.md`与`增强版验收报告.md`是本轮之前的历史记录。
