# FitFuel Pro 增强版

保留原15个真实HTML页面，184个动作、110种内置食物。动作/食物支持搜索、收藏、最近；自定义食物支持每100g/每份、kJ换算、编辑及历史快照。

打开 index.html 开始使用。建议最新版Edge/Chrome；可用本地服务器：在本目录运行 `python -m http.server 8000`，打开 http://localhost:8000/index.html。账户为原本地课程演示，不是服务端登录。

先设置身体档案 → 制定训练计划 → 今日执行打卡 → 搜索食物/自定义食物 → 记录饮食 → 分析与体重趋势。

营养表“拍照/上传”提供预览、手动录入、文字解析及确认保存；真实图片OCR服务未配置。接口说明见 OCR接口说明.md。没有拍菜估算。

localStorage数据保留fitfuel_键名及旧数据迁移；file与HTTP是不同存储来源，切换不会自动复制。压缩包backup目录保留原稳定网页版和原单文件，独立备份也随完整包交付。
